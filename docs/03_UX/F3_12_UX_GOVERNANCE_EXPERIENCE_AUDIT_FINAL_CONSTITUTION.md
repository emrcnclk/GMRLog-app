# 1. Mission

Protect the UX identity of GMRLOG over years of evolution.

The constitution exists so the product grows without losing itself.

F3.1–F3.11 locked **how GMRLOG should feel**.

F3.12 locks **how that feeling is defended**.

---

# 2. UX Constitution

Every UX decision must remain compatible with:

| Layer |
|-------|
| North Star |
| Product Constitution (Master · F1 · F2 · F2.29) |
| UX Constitution (F3.1–F3.11 · **this document**) |

If a new feature violates these principles,

**the feature changes — never the constitution.**

Silent drift is illegitimate (F2.29 kinship).

---

# 3. UX Governance

Every significant UX change should answer:

| Gate question |
|---------------|
| Does it improve clarity? |
| Does it reduce cognitive load? |
| Does it preserve trust? |
| Does it strengthen Digital Home? |
| Does it remain platform consistent? |

If not, it should not ship.

Governance is stewardship — not taste policing.

Align F2.29 Feature Acceptance · four reviews where major proposals apply (Product · Trust · Identity · Culture).

---

# 4. UX Decision Framework

When two UX solutions compete, priority order:

| Priority | Criterion |
|----------|-----------|
| 1 | User comprehension |
| 2 | Trust |
| 3 | Accessibility |
| 4 | Consistency |
| 5 | Performance |
| 6 | Delight |

Never the reverse.

Delight never outranks Trust or comprehension.

Engagement is not a listed criterion — and must not be inserted above these (F2.22 · F3.1).

---

# 5. UX Acceptance Criteria

Every feature should pass before release:

| Criterion | Anchors |
|-----------|---------|
| Orientation | F3.2 |
| Hierarchy | F3.3 |
| Interaction | F3.4 |
| Motion (if present) | F3.5 |
| Components / states / search | F3.6 |
| Digital Home surfaces | F3.7 |
| Home / Discover / Game | F3.8 |
| Community / Creator / Social | F3.9 |
| Cross-platform | F3.10 |
| Voice / language | F3.11 |
| Accessibility | F2.18 · F3.1 |
| Readability | F3.1 · F3.3 · F3.11 |
| Navigation | F2.1 · F3.2 |
| Consistency | This document · F3.1–F3.11 |
| Recoverability | F3.4 · F3.6 |
| Anti-manipulation | All F3 + F2 ethics |

Fail any critical gate → redesign — not “ship and fix later” as culture.

---

# 6. UX Audit Framework

Regular UX audits verify:

| Audit domain |
|--------------|
| Navigation consistency |
| Interaction consistency |
| Motion consistency |
| Voice consistency |
| Component behavior |
| Accessibility |
| Cross-device parity |
| Trust principles |
| Privacy principles |

Audit exists to **preserve quality**,

not to enforce personal taste.

Findings map to owners and resolution plans (§10).

---

# 7. UX Consistency Rules

No screen may invent its own:

| Forbidden invention |
|---------------------|
| Interaction language |
| Hierarchy |
| Navigation |
| Terminology |
| Motion philosophy |

Consistency is a product asset.

Recognizability depends on it (Master · F2.29).

---

# 8. UX Evolution Principles

The UX may evolve.

Its philosophy may not.

Evolution should:

| Should |
|--------|
| Simplify |
| Clarify |
| Improve accessibility |
| Reduce friction |
| Improve learnability |

Never:

| Never |
|-------|
| Chase trends |
| Imitate competitors’ identities |
| Increase engagement at the cost of trust |

Additive evolution — never destructive rewrite of room jobs or voice (F2.29 · F3.10).

---

# 9. Conflict Resolution

If documents disagree, priority:

```
North Star
  ↓
Master Direction
  ↓
F1
  ↓
F2 (incl. F2.29)
  ↓
F3 (F3.1–F3.11 · this document)
  ↓
Implementation
```

Lower layers never override higher layers.

Later F3 docs never silently overwrite earlier F3 constitutions — amendments must be explicit and LOCK-aware (F2.29 kinship).

On F2 vs F3 experience conflict: F2 product philosophy wins; F3 may not invent opposing meaning.

---

# 10. Design Debt Philosophy

Design debt should be treated like technical debt.

Temporary compromises must:

| Requirement |
|-------------|
| Be documented |
| Have an owner |
| Have a planned resolution |

Permanent inconsistency is unacceptable.

Debt that violates Trust · Privacy · Accessibility · Anti-manipulation is not “debt” — it is a ship blocker.

---

# 11. Future Expansion

Future UX work should **extend — never replace** — this constitution.

| Expansion |
|-----------|
| F4 UI Design implements under F1–F3 law |
| Later experience specs remain subordinate |
| Major constitutional changes require explicit governance review |
| No silent drift |

F3 series remains closed unless core UX philosophy itself changes.

---

# 12. Emotional Goal

The complete UX should make players feel:

> “Everything feels intentional.”

Never:

> “Different parts of the product feel designed by different teams.”

Never:

> “The product lost its identity over time.”

---

- [ ] Digital Home identity preserved  
- [ ] Calm interaction philosophy preserved  
- [ ] Navigation remains predictable  
- [ ] Visual hierarchy remains clear  
- [ ] Motion supports understanding  
- [ ] Components remain consistent  
- [ ] Search remains taste-first

- [ ] Fully compatible with F1 and F2  
- [ ] F3.1–F3.11 intact · this governance freeze locks them
