# 1. Mission

Define how money exists inside GMRLOG.

Money is a **consequence of value**.

Never the opposite.

| Law |
|-----|
| Revenue serves the ecosystem |
| The ecosystem never serves revenue |
| The product must never become optimized for monetization |
| Players always remain the protagonists |

Align North Star: a sustainable digital home for gaming culture — not a monetization OS wearing a culture skin.

---

# 2. Revenue Philosophy

Sustainable revenue exists so GMRLOG can remain independent, trustworthy, and long-lived.

| Revenue may fund | Revenue must never buy |
|------------------|------------------------|
| Product stewardship | Belonging |
| Trust & safety capacity | Trust itself |
| Creator tooling | Reputation |
| Culture infrastructure | Discovery ranking |
| Accessibility & global hospitality | Community authority |

| Always | Never |
|--------|--------|
| Value first · money follows | Money first · culture follows |
| Transparent commercial identity | Hidden paid influence |
| Optional paid enhancement | Mandatory paid belonging |
| Compatibility with F2.22 health | Optimization for addiction ARPU |

Vanity growth metrics must not become revenue law (F2.22 · F2.25).

---

# 3. Commerce Philosophy

Commerce is an **enhancement layer**.

Never the center of the platform.

| Commerce may | Commerce must never |
|--------------|---------------------|
| Reduce friction around optional value exchange | Become the protagonist |
| Support creators · studios · players with clear offers | Interrupt reading culture as default |
| Appear as labeled, dismissible context | Disguise ads as user content |
| Respect Library as archive — not launcher/storefront (F2.6) | Convert Wishlist into checkout coercion |

Six pillars remain equal (Master).

Commerce is not a seventh pillar that outranks them.

---

# 4. Creator Monetization

Creators may earn from craft (F2.12 Creator Economy).

| May | Must never |
|-----|------------|
| Support tools · tips · optional creator value paths (reserved) | Paywall core culture reading as caste |
| Transparent supporter relationships | Bought Known For / reputation (F2.13) |
| Human byline · craft before automation (F2.19) | AI content mills as monetized fake culture |
| Free path to become a creator | Creator ≠ automatic Premium caste (F2.16) |

Creator monetization sustains craft.

It does not sell authenticity.

---

# 5. Studio SaaS Philosophy

Studios may receive optional professional tooling (F2.24 future kinship).

| May | Must never |
|-----|------------|
| Organization tooling that aids official presence · insights | Buy influence · ranking · Community Trust |
| Non-exploitative org analytics posture (F2.23) | Surveil players into dark patterns |
| Clear Enterprise ≠ Premium boundary (F2.24 · F2.16) | Create two cultures: corp vs player |

Studio SaaS, if ever, is contribution infrastructure.

Not a license to own the graph.

---

# 6. Publisher Participation

Publishers communicate and may participate commercially with transparency (F2.24).

| May | Must never |
|-----|------------|
| Labeled commercial context where appropriate | Manipulate discovery |
| Official presence integrity | Sponsored ranking |
| Support games on the graph | Hidden advertising as organic posts |

Publisher money never becomes Discover law (F2.10).

---

# 7. Marketplace Philosophy

A marketplace, if ever reserved, is optional commerce around culture — not the product.

| May | Must never |
|-----|------------|
| Clear buyer/seller intent surfaces | Replace Library / Digital Home |
| Labeled goods distinct from user culture objects | Fake reviews for commerce (F2.17 · F2.19) |
| Player agency to ignore entirely | Forced marketplace tours for belonging |

Wishlist remains aspiration (F2.6) — not a storefront identity.

---

# 8. Affiliate Philosophy

Affiliates, if ever, are **labeled bridges** to external purchase contexts (F2.21 guests).

| May | Must never |
|-----|------------|
| Optional outbound convenience | Disguised endorsement as organic taste |
| Clear disclosure | Ranking purchased via affiliate performance |
| Player-dismissible | Convert Home into affiliate farm |

Affiliate value must not redefine recommendations (F2.19).

---

# 9. Sponsorship Philosophy

Sponsorships, if ever, are **transparent cultural partnerships** (F2.25 · F2.24).

| May | Must never |
|-----|------------|
| Clearly labeled sponsorship | Ads disguised as user content |
| Support events / programs without owning them (F2.15) | Interrupt long-form reading as default ad model |
| Align Trust · verification | Bought reputation or moderation outcomes |

Sponsorship strengthens culture only when honesty remains.

---

# 10. Premium Relationship

Premium remains F2.16.

| Rule |
|------|
| Premium enhances tools · expression · organization |
| Premium never creates two communities |
| Premium never paywalls culture |
| Premium badge ≠ reputation |
| Better filters OK · sold better recommendations forbidden |
| This freeze does not invent Premium prices or billing |

Commerce beyond Premium must obey the same anti-poison laws.

Enterprise tooling ≠ Premium membership (F2.24).

---

# 11. Commerce Ethics

Immutable ethics:

| Ethic |
|-------|
| Honest labeling of commercial content |
| Reading comfort before ad inventory (F2.18) |
| Safety before revenue (F2.17) |
| Agency before upsell (F2.20) |
| Culture before conversion (F2.25) |
| Craft before automation in monetized publishing (F2.12 · F2.19) |

Predatory monetization is constitutionally illegitimate — even if profitable.

---

# 12. Player Trust

Players trust Digital Home when money cannot rewrite identity.

| Trust requires |
|----------------|
| No selling belonging |
| No selling trust |
| No selling moderation |
| No selling community authority |
| Privacy not a paid unlock (F2.17 · F2.16) |
| Explainable commercial context — no mystery boosts |
| Calm defaults — no dark-pattern checkout (F2.20) |

If players must defend themselves from monetization, the economy failed.

---

# 13. Organization Boundaries

Organizations may participate commercially as contributors (F2.24).

| Boundary |
|----------|
| No organization buys platform centrality |
| No fake organizations for commerce |
| No deceptive promotion |
| No forced engagement for branded growth |
| Official presence ≠ purchased Discover |

Organization revenue paths must not invert player protagonism.

---

# 14. Relationship Graph

Commerce attaches as **optional edges**.

It does not become the root.

```
Players / Identity (protagonists)
  ↓
Games · Library · Discover · Home
  ↓
Communities · Creators · Legacy · Events
  ↓
Trust · Agency · Accessibility
  ↔
Commerce layer (enhancement only)
  ↔
Organizations / Premium / optional marketplace edges
```

| Money may | Money must not |
|-----------|----------------|
| Sustain nodes | Redefine nodes |
| Fund stewardship | Own culture |
| Enhance tools | Override pillars |

---

# 15. Anti-Manipulation

Explicitly forbid:

| Ban |
|-----|
| Pay-to-win |
| Bought reputation |
| Bought visibility |
| Bought discovery ranking |
| Ads that interrupt reading |
| Ads disguised as user content |
| Engagement-driven monetization |
| Predatory monetization |
| Gambling mechanics |
| Loot-box philosophy |
| Selling belonging |
| Selling trust |
| Selling moderation |
| Selling community authority |
| Battle-pass / engagement loot as growth revenue (F2.15 · F2.16 kinship) |
| AI fake reviews/personalities as monetized inventory (F2.19) |
| Growth hacks that convert invites into paid coercion (F2.25) |

If a revenue idea requires violating any prior freeze, it is rejected — regardless of forecast.

---

# 16. Future Ready

Reserve architecture only (no pricing · no billing · no providers):

| Capability |
|------------|
| Expanded Premium tooling under F2.16 ethics |
| Creator support / tipping posture |
| Optional marketplace layer |
| Labeled affiliate bridges |
| Transparent sponsorship slots for events/programs |
| Studio / organization professional tooling (SaaS posture) |
| Commerce transparency reporting kinship with F2.17 / F2.22 |

Architecture only.

---

# 17. Emotional Goal

The economy should feel like:

> “This home can sustain itself without selling who I am.”

Never:

> “Everything here is trying to charge me for belonging.”

And never:

> “Money decides what culture I see.”
