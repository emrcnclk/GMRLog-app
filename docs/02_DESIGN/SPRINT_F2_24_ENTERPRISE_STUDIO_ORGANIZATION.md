# 1. Mission

Define how professional organizations participate inside GMRLOG.

Organizations include:

| Kind |
|------|
| Game Studios |
| Publishers |
| Esports Organizations |
| Indie Teams |
| Universities |
| Gaming Clubs |
| Non-profit Organizations |
| Museums |
| Gaming Events |
| Research Institutions |

They contribute to gaming culture.

They do not own it.

Players remain the protagonists of Digital Home (F2.5.1).

---

# 2. Organization Philosophy

Organizations **support** culture.

Players remain protagonists.

| Always | Never |
|--------|-------|
| Transparent participation | Silent corporate takeover |
| Official clarity on the game graph | Dominating player spaces |
| Collaboration with creators & communities | Replacing creators or communities |
| Cultural contribution | Purchased centrality |
| Respect for Trust constitution | Deceptive promotion |

Six pillars remain equal (Master).

No organization becomes a seventh “owner pillar.”

---

# 3. Organization Types

Architecture only — directional vocabulary, not a ship taxonomy.

Examples:

| Type |
|------|
| Studio |
| Publisher |
| Esports Org |
| University |
| Club |
| Event Organizer |
| Foundation |

Indie teams may appear as studio-scale or creator-adjacent — still subordinate to player/culture primacy.

Types describe **role**.

They do not grant hierarchy over players.

---

# 4. Official Presence

Verified organizational identities enable:

| Capability |
|------------|
| Official communication |
| Clear association to games / events / programs |
| Transparency of who is speaking |

## Rules

| Rule |
|------|
| Verification is integrity — not prestige theater (F2.17) |
| Official ≠ automatically authoritative over player taste |
| Impersonation protection applies |
| Marketing never replaces transparency (F2.17 · F2.21) |

Official presence is a **label of clarity**.

Not a crown of ownership.

---

# 5. Studio Philosophy

Studios publish games.

They may support developers and interact with communities.

| Studios may | Studios must never |
|-------------|--------------------|
| Maintain official game-node presence | Dominate player spaces |
| Share developer diaries / official updates | Silence disagreement by corporate weight |
| Participate respectfully in communities | Buy Community Trust or leadership (F2.11 · F2.16) |
| Protect verified identity | Impersonate or astroturf |

Relationship-first Game Experience remains (F2.4): personal meaning before store/publisher walls.

---

# 6. Publisher Philosophy

Publishers communicate.

| Publishers may | Publishers must never |
|----------------|-----------------------|
| Announce · clarify · contextualize releases | Manipulate discovery |
| Link official channels as guests (F2.21) | Buy ranking / placement (F2.10 · F2.16) |
| Support transparency on the game graph | Hidden advertising as organic culture |

Taste-first Discover remains free and unbuyable.

Publisher voice is optional context — never Discover law.

---

# 7. Educational Organizations

Universities · student clubs · research · gaming education.

| May | Must never |
|-----|------------|
| Host learning · research · club culture | Turn education into engagement farms |
| Participate as cultural contributors | Claim ownership of player identity |
| Align accessibility & global dignity (F2.18) | Gate knowledge behind corporate caste |

Education expands culture access.

It does not redefine GMRLOG as LMS theater.

---

# 8. Event Organizations

Gaming festivals · competitions · community gatherings (F2.15).

| May | Must never |
|-----|------------|
| Organize real culture moments | Event battle-pass addiction |
| Partner without becoming platform foundation | Force attendance via FOMO analytics (F2.23) |
| Appear on Events surfaces | Override seasonal culture into corporate calendar only |

Events recognize culture.

They do not own the calendar of Digital Home.

---

# 9. Community Relationship

Organizations participate **inside** communities.

They never own communities.

| Law |
|-----|
| Community autonomy remains (F2.11) |
| Platform constitution remains supreme (F2.17) |
| Roles / Community Trust unbuyable |
| Org accounts are participants — not landlords |

If a community becomes a brand channel first, the philosophy failed.

---

# 10. Creator Relationship

Organizations collaborate with creators.

They never replace creators (F2.12).

| May | Must never |
|-----|------------|
| Commission · credit · amplify craft | Ghostwrite culture as org content mill |
| Respect human bylines | AI fake personalities for “official voice” abuse (F2.19) |
| Support creator protection | Buy Known For / reputation (F2.13 · F2.16) |

Creator path remains open to people — not only to studios.

---

# 11. Player Relationship

Players always retain agency (F2.20).

| Law |
|-----|
| Organizations never become the center of the platform |
| Follow / mute / block / hide remain player tools |
| No forced org visibility for belonging |
| Identity remains player-authored |
| Notifications stay calm — no corporate FOMO engine (F2.9 · F2.23) |

Digital Home belongs to the player.

Org presence is a guest in that home’s wider culture — not the landlord.

---

# 12. Trust

Verified organizations receive:

| Protection / duty |
|-------------------|
| Identity integrity |
| Impersonation protection |
| Transparent communication expectation |
| Accountability under platform constitution |

| Trust never means |
|-------------------|
| Immunity from critique |
| Purchased moderation outcomes |
| Hidden sponsored identity |
| Fake organizations |

Align F2.17 Developer Protection spirit — expanded to organization verification without creating a corporate caste.

---

# 13. Premium Boundary

**Enterprise ≠ Premium.**

| Rule |
|------|
| No organization buys influence |
| No organization buys reputation |
| No organization buys discovery ranking |
| No organization buys Community Trust / roles |
| Player Premium remains personal enhancement (F2.16) |
| Org tooling, if ever reserved, must not create two cultures |

Enterprise participation is cultural contribution posture.

Not a paid takeover tier.

---

# 14. Relationship Graph

Organizations connect to:

```
Games
Communities
Creators
Events
Articles
Guides
Collections
```

They **never override** the graph.

```
Players / Identity (protagonists)
  ↓
Games
  ↓
Communities · Creators · Legacy
  ↓
Events · Discover · Trust
  ↔
Organizations (contributors · optional official edges)
```

| Orgs may | Orgs must not |
|----------|---------------|
| Attach official edges | Become graph root |
| Enrich context | Redefine pillars |
| Collaborate | Own culture |

---

# 15. Anti-Manipulation

Explicit bans:

| Ban |
|-----|
| Purchased visibility |
| Sponsored ranking |
| Bought reputation |
| Hidden advertising |
| Fake organizations |
| Deceptive promotion |
| Forced engagement |
| Astroturfing as organic community |
| Corporate dominance of player spaces |
| Paywalled belonging via “official only” culture |

If influence is for sale, the constitution is violated.

Reserve architecture only:

# 17. Emotional Goal

Organizations should feel like:

> “Trusted participants in gaming culture.”

Never:

> “The platform belongs to corporations.”

And never:

> “Players are an audience for brands.”
