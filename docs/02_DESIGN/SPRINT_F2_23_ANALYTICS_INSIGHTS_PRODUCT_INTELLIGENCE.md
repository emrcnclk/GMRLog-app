# 1. Mission

Define how analytics exist inside GMRLOG.

Analytics exist to help:

| Audience | Understanding |
|----------|---------------|
| Players | Themselves |
| Creators | Their audience |
| Communities | Participation |
| Developers | Their products |

Analytics never exist to manipulate behavior.

Align North Star: a clearer Digital Home — not a denser scoreboard.

---

# 2. Analytics Philosophy

Insights are **mirrors**.

Not whips.

| Always | Never |
|--------|-------|
| Clarity | Judgment theater |
| Self-understanding | Behavioral pressure |
| Optional depth | Mandatory metric literacy |
| Calm summaries | Endless metric streams |
| Respect for privacy | Harvest for engagement |
| Compatibility with Legacy memory (F2.14) | Grind / streak optimization |

## Insight vs stewardship vs assistance

| Layer | Role |
|-------|------|
| F2.23 Insights | “What does my gaming life look like?” |
| F2.19 Assistance | “Can you help me explore / express?” |
| F2.22 Operations | “Is the ecosystem healthy?” |

None may optimize addiction.

---

# 3. Personal Insights

Personal insights help players understand their **gaming life**.

Architecture may reflect (philosophy only):

| Domain |
|--------|
| Gaming habits |
| Genre evolution |
| Taste evolution |
| Completion habits |
| Collection growth |

## Rules

| Rule |
|------|
| Descriptive — not competitive leaderboards |
| Player-authored history outranks empty sync noise (F2.21) |
| Hidden Archive / private shelves stay private (F2.6 · F2.20) |
| Never invent grind or shame for backlog |
| Known For remains qualitative reputation — not a metric wall (F2.13) |
| Premium may expand personal insight tools — never sell identity status (F2.16) |

Personal insights serve Identity / Digital Home (F2.5.1).

They do not redefine identity as a dashboard.

---

# 4. Creator Insights

Creator insights help creators understand reach and readership.

Architecture may reflect (philosophy only):

| Domain |
|--------|
| Reach understanding |
| Audience understanding |
| Article performance |
| Guide readership |

## Rules

| Rule |
|------|
| **Never vanity-first** |
| Craft before chart chasing (F2.12) |
| No engagement-score identity |
| No fake engagement inflation |
| Human byline remains; insights never replace authorship (F2.19) |
| Free culture reading remains; insights must not invent paywalled belonging |

Creator insights support craft decisions.

They must not turn creators into engagement laborers.

---

# 5. Community Insights

Community insights support **healthy participation** (F2.11).

| Healthy | Forbidden |
|---------|-----------|
| Understanding participation balance | Competitive engagement dashboards |
| Awareness of welcoming vs harmful patterns | Member shame scoreboards |
| Stewardship kinship with Trust (F2.17) | Outrage / controversy leaderboards |

Community Trust remains unbuyable (F2.16).

Insights never become Discord/Reddit clone metric theaters.

---

# 6. Developer Insights

Developer insights help verified developers **understand games** on the graph (F2.4 · F2.17).

| May help | Must never |
|----------|------------|
| Understand reception · relationship patterns at product level | Exploit players |
| Support official communication integrity | Dark-pattern player pressure |
| Remain subordinate to transparency | Replace marketing honesty |

Marketing does not replace transparency.

Developer insights are not a license for surveillance culture.

---

# 7. Product Insights

Product insights are **internal philosophy only**.

They inherit F2.22: ecosystem health over vanity growth.

| May ask | Must never ask as law |
|---------|----------------------|
| Is culture healthier? | How do we raise DAU at all costs? |
| Is Discover still taste-first? | How do we maximize session length? |
| Is Trust intact? | How do we farm clicks? |

No implementation.

No dashboards in this freeze.

No KPI formulas.

---

# 8. Privacy Principles

**Analytics belong to users — not the platform.**

| Principle |
|-----------|
| Privacy by default (F2.17) |
| Insights are not a Premium unlock of basic dignity (F2.16 kinship) |
| Players control visibility of personal insight surfaces (F2.20) |
| Creator / community / developer scopes stay least-privilege |
| External guest signals never quietly expand insight scope (F2.21) |
| Opt-out / calm defaults for optional insight depth |
| No cross-user private leakage in explanations |

Personal insight data is part of Digital Home ownership.

Not a free platform asset for manipulation.

---

# 9. Transparency

Explain where insights come from.

| Transparency requires |
|-----------------------|
| Plain-language provenance |
| Clear separation of authored vs imported signals |
| No mysterious personal “scores” as fate |
| Kinship with Trust > mystery (F2.3.1 · F2.17 · F2.19) |

If an insight cannot be explained without manipulation theater, it does not belong.

---

# 10. Relationship Graph

Analytics **observe**.

They never redefine.

```
Identity
  ↓
Games
  ↓
Communities
  ↓
Creators
  ↓
Legacy
```

| Insights may | Insights must not |
|--------------|-------------------|
| Reflect patterns across nodes | Rewrite pillar philosophy |
| Deepen self-understanding | Become the protagonist |
| Support Legacy memory (F2.14) | Convert memory into streak pressure |

Reputation (F2.13) remains recognition — not an analytics product.

---

# 11. Anti-Manipulation

Explicit bans:

| Ban |
|-----|
| Addictive dashboards |
| Streak optimization |
| Endless metrics |
| Vanity addiction |
| Behavioral pressure |
| FOMO analytics |
| Engagement scoring as identity |
| Shame for incomplete libraries |
| Competitive community metric walls |
| Using insights to override Settings agency (F2.20) |
| Sold “better insight ranking” that buys reputation (F2.16) |

If an insight exists mainly to keep someone opening the app, it is illegitimate.

---

# 12. Future Ready

Reserve architecture only:

| Capability |
|------------|
| Yearly reports |
| Gaming biography insights |
| Creator reports |
| Community reports |
| Developer dashboards (stewardship-safe · non-exploitative) |

Architecture only.

No implementation.

Align F2.14 yearbook / biography · F2.22 Platform Health Report kinship without merging into vanity growth.

---

# 13. Emotional Goal

Insights should feel like:

> “I understand my gaming life better.”

Never:

> “I feel judged by metrics.”

And never:

> “My worth is a chart.”

- [ ] Compatible with F1 · F2.1–F2.22 especially F2.16 · F2.17 · F2.19 · F2.20 · F2.22
