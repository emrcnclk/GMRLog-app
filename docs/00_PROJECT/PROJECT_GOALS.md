# Project Goals

## Purpose

This document defines the long-term vision, objectives, measurable success criteria, and strategic direction of the GMRLOG platform.

Every product decision, engineering task, design improvement, and business initiative should align with these goals.

---

# Vision Statement

**GMRLOG aims to become the world's leading social platform for gamers, combining game logging, reviews, collections, social networking, and developer interaction into a single ecosystem.**

Unlike traditional gaming databases or social media platforms, GMRLOG focuses on creating a personalized gaming identity where every player can document, share, discover, and discuss their gaming journey.

---

# Mission Statement

Our mission is to empower gamers by providing a platform where they can:

* Log every game they play.
* Share reviews and recommendations.
* Build meaningful collections.
* Create and share tier lists.
* Follow friends and creators.
* Discover new games through community activity.
* Interact directly with indie developers and studios.
* Express their gaming personality.

---

# Core Product Goals

## 1. Become the "Letterboxd for Games"

Players should be able to:

* Log games
* Rate games
* Review games
* Track playtime
* Track completion status
* Maintain gaming history
* Build personal gaming journals

---

## 2. Become the "Twitter/X for Gamers"

Users should be able to:

* Share short gaming thoughts
* Follow creators
* Follow friends
* Like posts
* Comment
* Repost
* Quote posts
* Join discussions around games

---

## 3. Build the Largest Gaming Community

Enable users to:

* Discover gamers with similar tastes
* Build friendships
* Join communities (future)
* Participate in events
* Share achievements
* Grow their gaming identity

---

## 4. Support Indie Developers

Verified developers and studios should be able to:

* Create official profiles
* Publish announcements
* Share development updates
* Post screenshots
* Publish trailers
* Promote upcoming games
* Interact directly with players
* Collect community feedback

---

## 5. Help Players Discover Games

Discovery should be powered by:

* Friends
* Reviews
* Collections
* Tier Lists
* Similar Games
* Personalized Recommendations (Future AI)
* Trending Content
* Developer Pages
* Studio Pages

# Design Goals

The UI should:

* Blend the simplicity of Letterboxd
* Capture the engagement of Twitter/X

# Non-Goals

GMRLOG is **not** intended to become:

* A game launcher
* A game store
* A live streaming platform
* A voice chat application
* A general-purpose social network
* A game engine
* A game development tool

The platform focuses on **gaming identity, discovery, discussion, and community**.

# Guiding Principles

Before implementing any feature, ask:

* Does it improve the player's gaming journey?
* Does it strengthen community interaction?
* Does it support long-term scalability?
* Does it align with the design system?
* Can it be maintained over time?
* Does it preserve a premium user experience?

If the answer is "no" to most of these questions, the feature should be reconsidered.
