## 2. Scope note

`GAME_API.yaml` predates D3.25 and — per `SPRINT_0_PROJECT_AUDIT.md` §1 — already
described fields (`igdbId`, `description`, `metacriticScore`, `hltbMain`) that
did not exist in the schema or code at audit time. D3.25 makes `igdbId` and
`description` real for the first time; it does **not** implement
`storyline`, `releaseStatus`, `metacriticScore`, `opencriticScore`,
`hltbMain`, or `hltbCompletionist` (no HowLongToBeat integration exists) or the
file's speculative DLC/edition/bundle endpoints. Those remain pre-existing,
unimplemented drift, called out in-line in the spec (see the comment above the
`Game` schema's new D3.25 block) and left for the general doc-truth pass
(audit Sprint 1), not fixed wholesale here — that would be a different, much
larger change outside this sprint's scope.

## 3. Changes

### 3.1 New paths

| Path | Method | operationId | Maps to |
|---|---|---|---|
| `/games/{gameId}/similar` | GET | `listGameSimilar` | `GamesController.listSimilar` |
| `/games/{gameId}/metadata` | GET | `getGameMetadataStatus` | `GamesController.getMetadataStatus` |

### 3.2 Reconciled path (not a new path — hence +2, not +3)

`/games/{gameId}/media` already existed as an unimplemented stub returning a
single `GameMedia` package object (`operationId: getGameMedia`). D3.25 is the
first sprint to actually implement this endpoint
(`GamesController.listMedia`), and the real shape is a flat, ordered array —
not the speculative package object. The path is reconciled in place:

- `operationId`: `getGameMedia` → `listGameMedia`
- Response schema: `GameMedia` (object, unimplemented) → array of
  `GameMediaItem` (implemented)

The old `GameMedia` schema is left in the spec, now unreferenced, rather than
deleted — deletion is a separate, reviewable decision outside an additive
change-control pass.

### 3.3 Extended schema — `Game`

Added to the existing `allOf` object (`components.schemas.Game`), all
optional/nullable, none removed or retyped:

`heroUrl`, `summary`, `trailerUrl`, `externalRating`, `externalRatingCount`,
`steamAppId`, `rawgId`, `tags[]`, `developers[]`, `publishers[]`, `franchise`,
`series`, `screenshots[]`, `metadata`.

### 3.4 New schemas

| Schema | Purpose |
|---|---|
| `NamedRef` | `{ id, name, slug }` — shared shape for genre/company/franchise/series refs |
| `GameTag` | `NamedRef` + `kind: theme\|mode\|perspective\|keyword` |
| `CompanyRef` | Alias of `NamedRef` (developers/publishers) |
| `GameMediaItem` | One mirrored media asset — kind, url, width, height, sortOrder |
| `GameRelatedGame` | Provider-declared relationship; `gameId` nullable until the target is matched into the catalog |
| `GameMetadataStatus` | `{ status, provider, refreshedAt, attribution }` — the enrichment lifecycle projection |

### 3.5 `GameCardResponse` (discovery/catalog list projections)

`packages/types/src/index.ts` — additive: `heroImageUrl: string | null`,
`summary: string | null`. Not yet reflected in `GAME_API.yaml`'s separate
`GameSummary` schema, which is its own pre-existing drift (see §2); tracked as
a carry-forward, not fixed here to avoid scope creep into an unrelated,
already-diverged file.

## 4. What did not change

- No existing path, operationId, or schema field was removed or renamed
  (aside from the intentional `getGameMedia` → `listGameMedia` reconciliation
  in §3.2, which corrects an operationId that never had a real implementation
  behind it).
- No response became less permissive (no field went from optional to
  required, no enum value was removed).
- All three new/reconciled endpoints are unauthenticated reads
  (`security: []`), matching `OptionalGuestGuard` on the live controller —
  consistent with the rest of the catalog's public-read posture.

## 5. Live contract vs. static spec

The authoritative, always-current contract is generated by NestJS Swagger from
`@ApiOperation`/typed-DTO decorators on `GamesController` and served at
`/docs-json` (verified by `smoke-d3-24-release-gate.mjs`, which asserts against
that live endpoint, not this file). This document and the `GAME_API.yaml` edits
keep the static spec honest for the surfaces D3.25 touches; they are not a
substitute for the live-generated contract.
