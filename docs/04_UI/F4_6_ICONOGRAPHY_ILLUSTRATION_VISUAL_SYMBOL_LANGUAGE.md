# 1. Mission

Define how visual symbols communicate meaning across GMRLOG **before** any icon or illustration is drawn.

Icons and illustrations exist to reinforce:

| Reinforce |
|-----------|
| Clarity |
| Orientation |
| Comprehension |
| Calm |
| Cultural belonging |

Visual symbols never exist to maximize engagement.

F4.1–F4.5 defined how the place looks and feels.

F4.6 defines how **symbols speak** inside that place — without drawing them yet.

---

# 2. Icon Philosophy

Icons communicate meaning.

Never decoration.

| Always | Never |
|--------|-------|
| Clarify | Decorate |
| Orient | Distract |
| Support labels | Replace understanding |
| Express confidence | Express excitement |
| Reduce cognitive load | Add visual noise |

An icon is a word in the visual language.

Not jewelry.

Align F4.1: clarify > decorate · F4.2: meaning before beauty.

---

# 3. Symbol Before Style

Every icon should answer:

> Why does this symbol exist?

before:

> Does it look cool?

Beauty follows meaning.

Style follows role.

If purpose cannot be stated, the symbol does not belong.

---

# 4. Semantic Icon System

Icons should be organized by **meaning**.

Future semantic families include:

| Family |
|--------|
| Navigation |
| Actions |
| Status |
| Community |
| Games |
| Library |
| Discovery |
| Profile |
| Collections |
| Reviews |
| Notifications |
| System |
| Moderation |

Only semantic roles — never graphics.

No family may exist solely for aesthetics.

Roles precede drawing. Assets arrive in later F4 / production work.

---

# 5. Illustration Philosophy

Illustrations exist when they serve a human moment.

Illustrations should:

| Should |
|--------|
| Reduce anxiety |
| Explain |
| Welcome |
| Celebrate meaningful moments |

Never:

| Never |
|-------|
| Fill empty screens |
| Distract |
| Decorate unnecessarily |

Empty space is often intentional (F4.4). Illustration is not a default filler.

Celebrate culture and belonging — not streaks, FOMO, or artificial reward spectacle (F3.11 · F4.1).

---

# 6. Gaming Identity Through Symbols

Gaming culture should appear through metaphor of **place and passion**:

| Through |
|---------|
| Atmosphere |
| Familiar gaming-life concepts |
| Identity and collection |
| Community and craft |

Never imitate:

| Never |
|-------|
| Esports clichés |
| RGB gamer stereotypes |
| Fantasy clichés |
| Sci-fi clichés |

Culture over costume.

Align F4.1 · F4.2 · F4.3: system and composition — not gamer cosplay.

---

# 7. Emotional Meaning

Icons should feel:

| Feel |
|------|
| Calm |
| Intelligent |
| Timeless |
| Intentional |

Never:

| Never |
|-------|
| Childish |
| Noisy |
| Flashy |
| Aggressive |

Symbol emotion matches F3 calm companion voice and F4.1 interface personality.

---

# 8. Recognition Philosophy

Screenshots should remain recognizable as GMRLOG even without relying on:

| Not required alone |
|--------------------|
| Logos |
| Colors |

because the **symbol language itself is consistent**.

Recognizability comes from:

| From |
|------|
| Shared metaphors |
| Predictable semantic roles |
| Consistent symbol grammar |
| Alignment with composition · hierarchy · spacing (F4.1 · F4.3 · F4.4) |

If removing brand chrome leaves an interchangeable icon soup, the philosophy failed.

---

# 9. Accessibility Relationship

Icons must never communicate meaning alone.

Meaning should always be reinforced by:

| Reinforced by |
|---------------|
| Labels |
| Hierarchy |
| Context |

Compatible with [F2.18](../02_DESIGN/SPRINT_F2_18_ACCESSIBILITY_GLOBAL_EXPERIENCE.md) · F3 · F4.2 (color alone banned) · F4.5 (effects alone banned).

Decorative icons must be treated as non-essential for understanding.

Accessibility is constitutional.

Not optional.

---

# 10. Consistency Rules

| Rule |
|------|
| Same action → same icon family |
| Same meaning → same symbol |
| Same metaphor everywhere |
| Never invent multiple symbols for identical concepts |
| Status symbols remain status · navigation remains navigation |
| Symbol hierarchy follows F3.3 |

Inconsistent symbol language is design debt (F3.12).

---

# 11. Anti-Manipulation

Explicit bans:

| Banned |
|--------|
| Attention-grabbing icons |
| Fake badges |
| Casino symbols |
| Exaggerated notification symbols |
| Deceptive visual emphasis |
| Reward explosions as default icon language |
| Symbols designed primarily to drive taps |

Icons must increase understanding.

Never engagement.

Align F2.22 · F2.29 · F3.12 · F4.1–F4.5.

---

# 12. Future Ready

Reserve architecture only (no assets · no libraries · no graphics):

| Reserved for later F4 / production |
|------------------------------------|
| Icon library |
| Illustration system |
| Achievement icons |
| Empty states |
| Onboarding illustrations |
| Moderation visuals |
| Seasonal art |

F4.6 defines the grammar.

Later work draws the words.

---

# 13. Emotional Goal

Players should feel:

> “The interface speaks a consistent visual language.”

Never:

> “Different parts of the app look like different products.”

Never:

> “The icons are trying to get my attention.”
